DataNusa — a national statistics site for Indonesia: real BPS figures for population, the economy, social indicators, and trade, on five linked pages with hand-drawn SVG charts, working filters, and a phone layout. Every figure carries its source and year.

## Run it

```sh
python3 -m http.server 8080 --directory app
```

Then open http://localhost:8080 in a browser. The hand-in program is `main.ts` (Node 22, standard library only): `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`.
